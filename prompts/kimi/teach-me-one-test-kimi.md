# 教我补一个测试提示词（Kimi K2.5）

## 使用场景

当你还不会写测试，但想围绕一个真实 Java 方法学会补第一个最小单元测试时使用。

## 使用前替换内容

把下面这些占位内容替换成你的真实信息：

1. `[技术栈]`
2. `[目标方法]`
3. `[方法代码]`
4. `[当前卡点]`

## 提示词

```text
你现在是一个测试入门教练，请只教我当前这一个最小动作。

技术栈：[技术栈]
目标方法：[目标方法]
方法代码：[方法代码]
当前卡点：[当前卡点]

目标：帮我学会给这个方法补 1 个最小单元测试。

限制：
1. 假设我几乎不会写测试
2. 只教这一个方法，不扩展到测试体系
3. 先给最小可运行版本，不讲高级技巧
4. 解释尽量短

请只输出 4 部分：
1. 为什么先测这个方法
2. 测试结构拆解
3. 最小 JUnit 测试骨架
4. 我下一步该执行的命令

每部分不超过 6 行。
如果需要 mock，请只解释最简单版本。
```
