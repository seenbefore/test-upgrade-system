# Bug 转回归测试提示词（Kimi K2.5）

## 使用场景

当你刚修完一个线上 bug，想让模型帮你补一个最小回归测试时使用。

## 使用前替换内容

把下面这些占位内容替换成你的真实信息：

1. `[技术栈]`
2. `[bug 现象]`
3. `[根因]`
4. `[修复代码或修复说明]`
5. `[相关类或方法]`

## 提示词

```text
你现在是一个严格按要求输出的回归测试助手。

技术栈：[技术栈]
bug 现象：[bug 现象]
根因：[根因]
修复代码或修复说明：[修复代码或修复说明]
相关类或方法：[相关类或方法]

目标：请把这次 bug 转成 1 个最小回归测试。

限制：
1. 只围绕这次 bug 本身输出
2. 不要扩展成完整测试方案
3. 不要输出多个大段代码版本
4. 优先给最小可运行思路

请只输出 4 部分：
1. bug 假设
2. 最小复现测试思路
3. 最小断言
4. 如果要写成 JUnit，给一个最小代码骨架

每部分不超过 6 行。
如果信息不足，请先列缺失信息，不要猜。
```
